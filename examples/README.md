# Selected code parts
`ee470_architecture_excerpt.py` contains selected original TensorFlow/Keras definitions, extracted from the supplied training script. Data paths, fitting, testing and personal Colab links are omitted. It was parsed statically; TensorFlow compatibility and historic-model reproduction are unverified.

`cs523_classical_recipe.py` is a later educational illustration of the StandardScaler → PCA(95% variance) → classifier recipe described in the CS523 report. Classifier defaults here are illustrative; this is not recovered original code or an exact historical parameter set. Use training-fold-only fitting if extending this example.

No full fitting loop, Optuna orchestration, pretrained weights or original deep-learning checkpoint is distributed. These files explain selected methods, while results remain source-grounded archived evidence.
