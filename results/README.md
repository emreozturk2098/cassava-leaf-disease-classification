# Archived results
The four CSV tables are transcribed from the supplied CS523 final report's table files. Mean ± standard deviation refers to its three validation folds. Rank/augmentation selection used those development folds. These tables do not represent a fresh training run or an independent final test.

EE470 main reporting uses the latest available numbered report `_3`: accuracy 55% and loss 1.6717 on 500 instructor-supplied test images. Its presentation instead reports 59.80%; that older/different statement is retained in the study notes and is not silently combined with the selected report. EE470 training accuracy 92.04% is a separate metric.

CS523's selected heavy_combo result has macro-F1 0.7921±0.0068 and accuracy 0.8855±0.0040. These cannot be interpreted as a directly comparable improvement over EE470's 55% because datasets, training methods and evaluation differ. See the two study documents and source manifest.
